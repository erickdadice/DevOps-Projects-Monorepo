# Python Básico

Este proyecto contiene scripts fundamentales para aprender los conceptos básicos del lenguaje Python, incluyendo:

- Variables y tipos de datos
- Strings y formateo
- Números y funciones matemáticas
- Control de flujo (`if`, comparadores)

## ▶️ Ejecución

Puedes ejecutar cualquier archivo desde terminal con:

```bash
python tipos/01-variables.py
```

## ✅ Mejores prácticas

- Scripts simples y didácticos
- Estructura modular por tema
