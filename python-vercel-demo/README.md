# Python FastAPI en Vercel

Este es un ejemplo mínimo de cómo desplegar una API con FastAPI en Vercel.

## Estructura

```
python-vercel-demo/
├── api/
│   └── index.py  # Punto de entrada de FastAPI
└── vercel.json   # Configuración para Vercel
```

## 🚀 Deploy en Vercel

1. Sube este repo a GitHub.
2. Ve a [vercel.com](https://vercel.com) y crea un proyecto.
3. Selecciona el repo y permite que Vercel detecte `vercel.json`.
4. El proyecto se desplegará automáticamente.
